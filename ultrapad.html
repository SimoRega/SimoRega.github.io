Architettura & Stack UltraPad

Questa schermata illustra l'architettura tecnica prevista per lo sviluppo finale, utile a fini di presentazione o validazione tecnica con il cliente.

Backend (Spring Boot & Security)

  • Java 17 / Spring Boot: Core engine con Maven per la gestione delle dipendenze.
  • Spring Security: Configurazione JWT stateless + OAuth2 per Google login.
  • MongoDB: Storage NoSQL flessibile per document model strutturati a blocchi.

Frontend (React & PWA)

  • React.js (ES6+): Interfaccia reattiva a componenti.
  • State Management: Redux Toolkit per coordinamento globale dei dati.
  • Offline-First: Utilizzo di Service Worker e IndexedDB (tramite Workbox) per buffering dei salvataggi quando offline.

UI & Componenti Editor

  • Tailwind CSS: Layout moderno a griglie, flessibile, responsive ed ottimizzato per temi multipli.
  • QuillJS Integration: Core editor di testo semantico per note ricche.
